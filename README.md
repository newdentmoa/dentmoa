# 덴트모아 (dentmoa)

**치과의사 구인공고를 하루 3번 모아서, 내 조건에 맞는 공고만 텔레그램과 메일로 알려 주는 개인용 프로그램**입니다.

여러 사이트와 병원 홈페이지를 매일 돌아다니며 확인하지 않아도 됩니다.
서버가 정해진 시각마다 사이트를 조용히 읽고, 공고를 분류해서, 조건에 맞는 새 공고만 3줄 요약과 함께 보내 줍니다.

---

## 무엇을 하나요?

### 1. 여러 곳의 공고를 한곳에 모읍니다

| 출처 | 어떤 공고가 올라오나요 |
|---|---|
| **모어덴** | 치과의사 커뮤니티 구인 게시판 (로그인 필요) |
| **덴트포토** | 치과의사 커뮤니티 구인 게시판 (로그인 필요) |
| **잡알리오** | 공공기관 채용 — 국립대학교 치과병원(서울대·경북대·부산대·전남대·전북대·강릉원주대), 국립중앙의료원, 보훈병원 등 |
| **하이브레인넷** | 대학 교원 채용 — 치과대학·치의학전문대학원 교수 |
| **나라일터** | 정부·지자체 채용 — 보건소 치과의사(임기제공무원), 국립병원·교정시설 |
| **병원 채용 게시판 66곳** | 치과대학병원·대학병원·장애인치과병원·공공병원 홈페이지의 채용 게시판과 병원들이 쓰는 채용 사이트(recruiter.co.kr·인크루트) |

여러 출처에 똑같이 올라온 공고는 하나로 묶어서 한 번만 알려 줍니다.

### 2. 공고를 자동으로 분류합니다

AI가 아니라 **정해진 규칙(낱말)** 으로 분류합니다. 그래서 왜 그렇게 분류했는지 근거를 항상 보여 줄 수 있습니다.

- **기관 종류** — 치과대학병원·치과대학 / 대학병원 치과 / 종합병원·병원 치과 / 공공병원·보건소 / 장애인치과병원·구강진료센터 / 치과병원 / 치과의원
- **직위** — 전임교원 / 임상교수·진료교수 / 전임의·임상강사 / 촉탁의·계약직·임기제 / 봉직의 / 전공의
- **분과** — 소아치과, 교정과, 구강외과 등 11개 분과 + 일반의 혹은 분과무관 + 기초치의학
- **근무 형태** — 풀타임 / 파트타임 / 대진
- **지역** — 시·도와 구·시·군 (2026년 행정구역 기준)
- **마감일** — 글에서 찾아 D-day로 표시

### 3. 조건에 맞는 새 공고만 알려 줍니다

- **텔레그램**과 **메일**로 받습니다. 둘 중 하나만 써도 됩니다.
- 공고마다 기관·직위·분과·지역·마감일과 **본문 3줄 요약**, 원문 링크가 붙습니다.
- 마감이 다가오면 **마감 임박 알림**을 한 번 더 보냅니다.
- 로그인 실패처럼 확인이 필요한 일이 생기면 알림에 함께 적어 줍니다. 사이트 접속 실패는 한두 번으로는 알리지 않고
  (다음 수집 때 놓친 글까지 따라잡습니다) **연속 3번**(약 하루) 실패했을 때만 알립니다.

### 4. 휴대폰으로 보는 대시보드

휴대폰이나 컴퓨터 브라우저에서 열 수 있는 나만의 화면(비밀번호로 보호)입니다.

- **공고 모아보기** — 내 조건에 맞는 공고 / 전체 공고 / 관심(★) 공고
- **검색·필터** — 검색어, 기관 종류, 직위, 분과, 근무 형태, 시·도, 출처, 기간
- **★ 관심 표시**와 **숨기기**
- 공고마다 **"왜 이렇게 분류됐나요?"** — 분류 결과와 근거가 된 말
- **알림 조건** — 체크박스로 조건 고르기, 알림 시각 정하기
- **계정·연결** — 사이트 아이디·비밀번호, 텔레그램, 메일 설정과 테스트 버튼
- **상태** — 사이트별 마지막 수집 결과, 실행 기록, 지금 바로 실행

### 5. 사이트를 조용히 읽습니다

- 하루 3번만 확인합니다 (기본 08:10 · 12:40 · 18:20 무렵, 매번 몇 분씩 무작위로 늦춤).
- 글을 하나 열 때마다 3~8초씩 쉬고, 이미 본 글은 다시 열지 않습니다.
- 로그인 상태(쿠키)를 다시 써서 매번 로그인하지 않습니다.
- 서버를 **한국(서울)** 에 두어 평소 로그인처럼 보이게 합니다. 국내 사이트는 해외 접속 로그인을 막거나 의심할 수 있기 때문입니다.

## 어떻게 돌아가나요?

```
 모어덴 · 덴트포토 · 잡알리오 · 하이브레인넷 · 나라일터 · 병원 게시판 66곳
        │  하루 3번, 천천히 읽기
        ▼
 [서버 — AWS Lightsail 서울, 24시간 켜짐]
    1. 수집   새 글만 열어 보기
    2. 분류   기관 종류·직위·분과·근무 형태·지역·마감일 (규칙)
    3. 저장   data/dentmoa.sqlite3 파일 하나
    4. 묶기   여러 출처에 올라온 같은 공고를 하나로
    5. 비교   내 알림 조건과 맞는지
        │
        ├──▶ 텔레그램 · 메일   (3줄 요약, 마감 임박 알림)
        └──▶ 대시보드          (https 주소, 휴대폰·컴퓨터 브라우저, 비밀번호)
```

- **서버**: 집 컴퓨터를 켜 둘 필요 없이, 아마존(AWS)의 작은 서버를 빌려 24시간 돌립니다. 비용은 월 몇천 원~1만 원 안팎입니다 (정확한 가격은 가입 화면에서 확인).
- **프로그램 묶음(도커)**: 프로그램과 필요한 것(파이썬, 브라우저, 한글 글꼴)을 한 상자에 담아 설치합니다. 설치는 명령 한 줄이면 됩니다.
- **https 주소**: 웹 서버(Caddy)가 보안 인증서를 자동으로 받아 `https://3-35-123-45.sslip.io` 같은 주소를 만듭니다. 도메인을 사지 않아도 됩니다.
- **저장**: 공고·설정·계정 정보가 서버의 파일 하나(`data/dentmoa.sqlite3`)에 저장됩니다. 매일 새벽 자동으로 백업합니다.
- **비밀번호·토큰**: 코드나 GitHub에는 절대 넣지 않습니다. 대시보드의 **계정·연결** 화면에서 입력하면 서버에만 저장됩니다.

## 지금 상태 (알아 두실 점)

- 2026년 10월에 실제 사이트에 접속해서 수집기를 실제 화면에 맞췄습니다. 잡알리오·하이브레인넷·나라일터·병원 게시판은 실제로 공고를 가져오는 것까지 확인했습니다.
- 연세대 치과대학병원(세브란스 계열), 경희대치과병원·강동경희대치과병원(인크루트), 서울시장애인치과병원(서울대치과병원 채용 사이트)처럼 **채용 전문 사이트를 쓰는 병원**도 이제 직접 읽습니다.
- **모어덴·덴트포토**도 실제 계정으로 로그인해서 공고를 가져오는 것까지 확인했습니다. 두 사이트에 함께 올라온 같은 공고는 한 번만 알려 드립니다.
- 일부 병원 게시판은 주소가 없어졌거나 자바스크립트로만 보이는 화면이라 읽지 않습니다(2026-10-10 새 주소를 다시 찾아 9곳을 되살림). 이런 곳의 공고 대부분은 잡알리오·하이브레인넷·나라일터에도 올라와서 그쪽에서 잡힙니다.
- 사이트가 화면을 바꾸면 알림에 **"사이트 화면 구조가 바뀐 것 같아요"** 경고가 옵니다. 고치는 방법은 [docs/6-문제해결.md](docs/6-문제해결.md)에 있습니다.

## 개발자용

파이썬 3.11 이상이 필요합니다. 자세한 구조와 원칙은 [CLAUDE.md](CLAUDE.md)를 보세요.

```bash
python -m venv .venv
. .venv/bin/activate                     # 윈도우: .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m playwright install chromium    # 브라우저로 읽는 사이트(모어덴·덴트포토)용 (선택)

python -m pytest                         # 테스트 (네트워크 없이 tests/fixtures 의 HTML 사용)
python -m dentmoa serve                  # 대시보드 + 예약 작업 → http://localhost:8000
```

자주 쓰는 명령 (`python -m dentmoa --help` 로 전체 보기):

| 명령 | 하는 일 |
|---|---|
| `python -m dentmoa serve` | 대시보드와 예약 작업 실행 |
| `python -m dentmoa run-once` | 지금 한 번 수집 → 알림 → 마감 알림 |
| `python -m dentmoa notify --dry-run` | 보낼 알림을 미리 보기만 |
| `python -m dentmoa probe moreden` | 사이트 화면(HTML)을 `data/debug` 에 저장 (구조 진단) |
| `python -m dentmoa classify "제목" "본문"` | 분류 결과와 근거 보기 |
| `python -m dentmoa reclassify` | 저장된 공고 다시 분류 |
| `python -m dentmoa set-password` | 대시보드 비밀번호 정하기 |

환경변수 (모두 선택):

| 이름 | 뜻 |
|---|---|
| `DENTMOA_DATA` | 데이터 폴더 (기본 `./data`, 도커에서는 `/data`) |
| `DENTMOA_BASE_URL` | 알림에 넣을 대시보드 주소 (예: `https://3-35-123-45.sslip.io`) |
| `DENTMOA_HOST`, `DENTMOA_PORT` | 웹 서버 주소·포트 (기본 `0.0.0.0`, `8000`) |
| `DENTMOA_SECURE_COOKIES=1` | https 에서만 로그인 쿠키 전송 |
| `DENTMOA_BEHIND_PROXY=1` | 앞단 웹 서버(Caddy)가 알려주는 접속 IP를 믿음 (도커 구성에서 자동 설정) |
| `ADMIN_PASSWORD` | 처음 시작할 때 대시보드 비밀번호 (이미 있으면 무시) |
| `MOREDEN_ID`, `MOREDEN_PW`, `DENTPHOTO_ID`, `DENTPHOTO_PW` | 사이트 계정 (보통은 대시보드에서 입력) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | 텔레그램 (보통은 대시보드에서 입력) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `EMAIL_TO` | 메일 (보통은 대시보드에서 입력) |

서버 배포 파일은 `Dockerfile`과 `deploy/` 폴더에 있습니다 (`install.sh`, `update.sh`, `backup.sh`, `docker-compose.yml`, `Caddyfile`, `env.example`).
