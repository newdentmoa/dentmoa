텔레그램 알림 설정 방법 (처음이라면 펼쳐 보세요)
  1. 휴대폰 텔레그램 앱 검색창에 @BotFather를 검색해 대화를 엽니다. (이름 옆에 파란 체크 표시가 있는 공식 계정)
  2. 대화창에 /newbot 을 보냅니다.
  3. 봇 이름을 물어보면 아무 이름이나 보냅니다. (예: 덴트모아 알림)
  4. 봇 아이디(username)를 물어보면 영어로 정해서 보냅니다. 반드시 bot으로 끝나야 해요. (예: dentmoa_kim_bot) 이미 있는 이름이면 다른 이름을 보내세요.
  5. BotFather가 보내 준 메시지에서 토큰(123456789:AAH… 처럼 긴 글자)을 길게 눌러 복사합니다.
  6. 아래 '봇 토큰' 칸에 붙여넣고 저장을 누릅니다.
  7. BotFather 메시지의 t.me/… 링크를 눌러 내 봇을 열고 시작(/start)을 누릅니다.
  8. 이 화면 아래 받는 사람 칸에서 채팅 ID 자동 찾기를 누릅니다.
  9. 테스트 메시지를 눌러 텔레그램에 메시지가 오는지 확인합니다.
{% if many %}

Gmail 앱 비밀번호 만드는 방법 (처음이라면 펼쳐 보세요)
  1. 알림을 보낼 Gmail 계정으로 로그인한 뒤, 오른쪽 위 프로필 사진 → Google 계정 관리로 갑니다.
  2. 보안 메뉴를 누릅니다. (휴대폰에서는 위쪽 탭)
  3. 2단계 인증을 켭니다. 이미 켜져 있으면 다음으로 넘어가세요.
  4. 위쪽 검색창에 앱 비밀번호를 검색해 들어갑니다. (2단계 인증이 켜져 있어야 보여요)
  5. 앱 이름에 '덴트모아'라고 적고 만들기를 누릅니다.
  6. 화면에 나온 16자리 비밀번호를 복사해 아래 '앱 비밀번호' 칸에 붙여넣습니다. 띄어쓰기는 있어도 괜찮아요.
  7. '보내는 Gmail 주소'에 그 Gmail 주소를 적고 저장합니다. 알림을 받을 주소(같은 주소여도 돼요)는 아래 받는 사람 칸에 적습니다.
  8. 메일 테스트를 눌러 메일이 오는지 확인합니다. 안 보이면 스팸함도 확인해 주세요.
