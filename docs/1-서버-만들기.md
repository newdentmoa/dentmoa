# 1. 서버 만들기 (AWS Lightsail · 서울)

덴트모아는 하루 종일 켜져 있는 작은 컴퓨터(**서버**)에서 돌아갑니다.
집 컴퓨터를 계속 켜 둘 필요 없이, 아마존(AWS)의 **Lightsail** 서비스에서 작은 서버를 빌립니다.

> **왜 서울 서버인가요?**
> 모어덴·덴트포토 같은 국내 사이트는 해외에서 로그인하면 막거나 수상한 로그인으로 볼 수 있습니다.
> 서울에 있는 서버는 한국 IP 주소를 쓰기 때문에 평소 로그인처럼 보입니다.

**걸리는 시간:** 20~30분
**준비물**

- 컴퓨터(윈도우) — 처음 설정은 휴대폰보다 컴퓨터가 훨씬 편합니다.
- 이메일 주소
- 해외 결제가 되는 카드 (Visa, Mastercard 등)
- 휴대폰 (문자 인증)

**비용:** 월 몇천 원~1만 원 안팎입니다. 정확한 가격은 서버 플랜을 고르는 화면에 나오니 그 화면에서 확인하세요.
메모리 **1GB 이상** 플랜 중 가장 작은 것을 고르면 됩니다. 처음 가입하면 일정 기간 무료 혜택이 있을 수 있는데, 이것도 화면에 표시됩니다.

> 화면의 메뉴 이름은 AWS가 화면을 바꾸면서 조금씩 달라질 수 있습니다. 비슷한 이름을 찾아 누르면 됩니다.

---

## 1단계. AWS 가입하기

1. 컴퓨터 브라우저에서 <https://aws.amazon.com/ko/> 에 들어갑니다.
2. 오른쪽 위의 **AWS 계정 생성**(또는 **무료로 시작하기**)을 누릅니다.
3. **루트 사용자 이메일 주소**와 **AWS 계정 이름**(예: `dentmoa`)을 적고 **이메일 주소 확인**을 누릅니다.
4. 메일로 온 **인증 코드**를 넣고, 로그인에 쓸 **루트 사용자 암호**를 정합니다.
5. **연락처 정보**
   - 용도는 **개인 - 개인 프로젝트용**을 고릅니다.
   - 이름과 주소는 **영어로** 적어야 합니다. 집 주소의 영문 표기는 [도로명주소 안내시스템](https://www.juso.go.kr)에서 주소를 검색하면 **영문보기**로 알 수 있습니다.
6. **결제 정보**: 카드 번호를 넣습니다. 카드 확인용으로 아주 작은 금액이 승인됐다가 취소될 수 있습니다.
7. **자격 증명 확인**: 휴대폰 번호(국가 코드 대한민국 +82)를 넣고 **문자 메시지(SMS)** 로 온 번호를 입력합니다.
8. **Support 플랜**: **기본 지원 - 무료**를 고르고 **가입 완료**를 누릅니다.
9. 가입 화면에서 **무료 플랜 / 유료 플랜**을 고르라고 나오면, 서버를 계속 켜 둘 것이므로 **유료 플랜**을 권합니다. 무료 플랜은 기간이 끝나면 계정이 닫히거나 일부 서비스를 못 쓸 수 있습니다. 정확한 조건은 그 화면의 설명을 꼭 읽어 보세요. (이런 선택 화면이 없으면 그냥 넘어가면 됩니다.)
10. **AWS Management Console로 이동** → **루트 사용자**로 로그인합니다.

**화면을 한국어로 바꾸기:** 콘솔 오른쪽 위의 톱니바퀴(⚙ 설정) 또는 화면 맨 아래의 언어 메뉴에서 **한국어**를 고릅니다.

> **(권장) 계정 보안:** 콘솔 오른쪽 위 계정 이름 → **보안 자격 증명** → **MFA 할당**에서 휴대폰 인증 앱(Google Authenticator 등)을 연결해 두면, 비밀번호가 새도 다른 사람이 로그인할 수 없습니다.

## 2단계. 서버(인스턴스) 만들기

1. <https://lightsail.aws.amazon.com> 에 들어갑니다. (또는 AWS 콘솔 맨 위 검색창에 `Lightsail` 을 검색)
   - Lightsail 화면이 영어라면, 화면 오른쪽 위 계정 메뉴나 맨 아래쪽에서 언어를 **한국어**로 바꿀 수 있습니다.
2. **인스턴스 생성** 버튼을 누릅니다.
3. **인스턴스 위치 선택**
   - **AWS 리전 및 가용 영역 변경**을 누르고 **서울 (ap-northeast-2)** 을 고릅니다. ← **가장 중요합니다**
   - 가용 영역은 아무거나 괜찮습니다 (보통 `a`).
4. **인스턴스 이미지 선택**
   - 플랫폼: **Linux/Unix**
   - 블루프린트: **운영 체제(OS) 전용** 탭 → **Ubuntu 24.04 LTS**
   - ('앱 + OS' 탭의 WordPress 같은 것은 고르지 마세요.)
5. 그 아래 **선택 사항**(시작 스크립트, SSH 키, 자동 스냅샷)은 그대로 둡니다.
6. **인스턴스 플랜 선택**
   - 네트워크 유형: **듀얼 스택** (※ **IPv6 전용**은 고르지 마세요. 설치가 되지 않습니다.)
   - 크기: 메모리 **1GB 이상** 중 가장 작은 플랜. 화면에 월 요금이 함께 나옵니다.
   - (메모리 512MB 플랜은 부족합니다. 일부 사이트를 읽을 때 브라우저를 쓰기 때문입니다.)
7. **인스턴스 이름 지정**: `dentmoa` 라고 적습니다.
8. 맨 아래 **인스턴스 생성**을 누릅니다.
9. 인스턴스 목록에 `dentmoa` 가 생기고, 1~2분 뒤 상태가 **실행 중**으로 바뀝니다.

## 3단계. 고정 IP 만들기

서버의 주소(IP)는 서버를 껐다 켜면 바뀔 수 있습니다. **고정 IP**를 붙이면 주소가 바뀌지 않습니다.
고정 IP는 서버에 연결되어 있는 동안에는 따로 요금이 없습니다. (연결하지 않고 남겨 두면 요금이 나옵니다.)

> **꼭 설치(2장) 전에 하세요.** 설치할 때 이 IP로 대시보드 주소를 만들기 때문입니다.

1. Lightsail 첫 화면 위쪽의 **네트워킹** 탭을 누릅니다.
2. **고정 IP 생성**을 누릅니다.
3. 위치가 **서울**인지 확인합니다.
4. **인스턴스에 연결** 에서 `dentmoa` 를 고릅니다.
5. 이름(예: `dentmoa-ip`)을 적고 **생성**을 누릅니다.
6. 화면에 나온 IP 주소(예: `3.35.123.45`)를 메모해 둡니다.

---

## 4단계. 방화벽 열기 (HTTP 80, HTTPS 443)

밖에서 대시보드에 들어올 수 있도록 문을 엽니다.

1. Lightsail 첫 화면의 **인스턴스** 탭에서 `dentmoa` 이름을 누릅니다.
2. **네트워킹** 탭을 누릅니다.
3. **IPv4 방화벽** 부분을 봅니다. 처음에는 보통 **SSH (22)** 와 **HTTP (80)** 가 있습니다.
4. **+ 규칙 추가**를 누릅니다.
   - 애플리케이션: **HTTPS** 를 고릅니다 (포트 443이 자동으로 들어갑니다).
   - **생성**을 누릅니다.
5. **HTTP (80)** 가 없다면 같은 방법으로 **HTTP** 도 추가합니다.

다 되면 IPv4 방화벽이 이렇게 보여야 합니다.

| 애플리케이션 | 프로토콜 | 포트 |
|---|---|---|
| SSH | TCP | 22 |
| HTTP | TCP | 80 |
| HTTPS | TCP | 443 |

- **80번도 지우지 마세요.** 보안 인증서(https)를 받을 때 필요합니다.
- **IPv6 방화벽**은 그대로 둬도 됩니다.

## 5단계. 서버에 접속하기 (브라우저 SSH)

서버에 명령을 입력할 수 있는 검은 화면(터미널)을 엽니다. 따로 프로그램을 설치할 필요가 없습니다.

1. `dentmoa` 인스턴스 화면에서 **연결** 탭을 누릅니다.
2. **SSH를 사용하여 연결** 버튼을 누릅니다.
   (인스턴스 목록에서 `dentmoa` 카드의 **터미널 모양 아이콘**을 눌러도 됩니다.)
3. 새 창이 열리고 잠시 뒤 아래처럼 보이면 성공입니다.
   ```
   ubuntu@ip-172-26-1-23:~$
   ```

**이 창을 쓰는 요령**

- **붙여넣기:** 먼저 `Ctrl + V` 또는 `Ctrl + Shift + V` 를 눌러 봅니다. 안 되면 창 오른쪽 아래의 **클립보드 아이콘**을 눌러 나오는 칸에 붙여넣은 다음, 검은 화면에서 마우스 **오른쪽 버튼**을 누릅니다. (버전에 따라 방법이 조금 다를 수 있습니다.)
- **복사:** 마우스로 글자를 드래그해서 고르면 복사됩니다.
- 창이 끊기거나 닫혀도 서버는 계속 켜져 있습니다. 다시 **SSH를 사용하여 연결**을 누르면 됩니다.

여기까지 됐으면 → **[2. 설치하기](2-설치하기.md)** 로 넘어갑니다. 이 SSH 창은 열어 두세요.

## 다른 방법: Oracle Cloud 무료 서버 (어려움)

Oracle Cloud의 **Always Free(평생 무료)** 서버도 **서울** 또는 **춘천** 리전에서 쓸 수 있습니다. 돈이 들지 않는 대신 훨씬 어렵습니다.

- 가입할 때 고른 **홈 리전**은 나중에 바꿀 수 없습니다. 반드시 서울(South Korea Central) 또는 춘천(South Korea North)을 고르세요.
- 무료 서버 자리가 모자라 "Out of capacity" 오류로 서버가 만들어지지 않는 일이 잦습니다.
- 방화벽을 **두 군데**(클라우드 화면의 보안 목록 + 서버 안의 iptables) 모두 직접 열어야 합니다. 덴트모아 설치 스크립트는 서버 안의 방화벽까지는 열어 주지 않습니다.
- 메뉴가 복잡하고 영어 위주이며, 오래 거의 쓰지 않는 무료 서버를 회수할 수 있다는 정책도 있습니다.

컴퓨터에 익숙하지 않다면 **Lightsail을 권합니다.**
