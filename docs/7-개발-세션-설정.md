# 개발 세션 설정 — Claude가 실제 사이트에 접속할 수 있게 하기

> 이 문서는 **프로그램을 고치거나 마무리할 때(Claude Code 세션)** 필요한 설정입니다.
> 실제로 매일 알림을 받는 **서버**의 아이디·비밀번호는 대시보드의 **계정·연결** 화면에 넣습니다. 이 문서와는 별개입니다.

## 왜 필요한가요?

처음 프로그램을 만든 세션은 네트워크가 막혀 있었습니다. 2026년 10월 세션들에서 실제 사이트에 접속해 수집기를 맞췄고,
**모어덴·덴트포토도 로그인 뒤 화면까지 확인해서 마무리했습니다.**
나중에 사이트가 화면을 바꿔서 수집기를 고쳐야 할 때, Claude가 실제 화면을 보려면 다음 두 가지를 설정해야 합니다.

1. Claude 작업 환경에서 외부 사이트 접속 허용
2. 모어덴·덴트포토 로그인 정보를 **환경 변수**로 등록 (채팅창에 비밀번호를 쓰지 않기 위해서)

## 1. 네트워크 접근 허용

1. Claude Code(웹 또는 앱) 세션 화면 위쪽에 있는 **클라우드 환경 이름**을 누르고 **편집(Edit)** 을 누릅니다.
2. **네트워크 접근(Network access)** 항목에서 둘 중 하나를 고릅니다.
   - **가장 간단한 방법:** 전체 허용(Full) 수준으로 바꿉니다. 병원 게시판만 50곳이 넘어서 이 방법을 추천합니다.
   - **허용할 주소만 넣는 방법:** 제한(Limited) 수준을 고르고 **허용 도메인(Allowed domains)** 에 아래 주소들을 추가합니다. 이때 **패키지 관리자 허용(Allow package managers)** 체크는 그대로 둡니다.
     ```
     moreden.co.kr, www.moreden.co.kr, public-api.moreden.co.kr, auth.deneer.co.kr,
     board.dentphoto.com, member.dentphoto.com, www.dentphoto.com, dentphoto.com,
     job.alio.go.kr, www.hibrain.net, hibrain.net, www.gojobs.go.kr
     ```
     병원 게시판 주소는 `dentmoa/data/institutions.json` 에서 `"watch": true` 인 항목의 `recruit_url` 들입니다.

자세한 설명(영문): https://code.claude.com/docs/en/cloud-environments#network-access
메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.

## 2. 로그인 정보 등록 (환경 변수)

같은 편집 화면의 **환경 변수(Environment variables)** 칸에 한 줄에 하나씩 적습니다.

```
MOREDEN_ID=모어덴아이디
MOREDEN_PW=모어덴비밀번호
DENTPHOTO_ID=덴트포토아이디
DENTPHOTO_PW=덴트포토비밀번호
```

- 모어덴은 **카카오 로그인이 아닌 아이디·비밀번호 로그인**용 정보를 넣어 주세요.
- 비밀번호에 `#` 이나 `$` 가 있으면 **작은따옴표로 감싸** 주세요. 감싸지 않으면 `#` 뒤는 지워지고 `$` 는 다른 값으로 바뀝니다.
  예) `MOREDEN_PW='ab#cd$12'` (큰따옴표 `"` 는 쓰지 마세요)
- 값을 고친 뒤에는 **새 세션**을 열어야 바뀐 값이 들어옵니다.
- 이 값은 Claude 작업 환경 안에서만 쓰입니다. 코드나 GitHub에는 저장되지 않습니다.
- **채팅창에는 비밀번호를 절대 쓰지 마세요.**

## 3. 새 세션 시작

설정은 **새로 시작하는 세션부터** 적용됩니다.

1. 저장소 `newdentmoa/dentmoa` 의 기본 브랜치(저장소 첫 화면에 보이는 브랜치)로 새 세션을 엽니다.
2. 첫 메시지로 이렇게 보내면 됩니다. (사이트 이름은 알림에서 '화면 구조가 바뀐 것 같아요'라고 한 곳으로)

   > 모어덴 화면이 바뀐 것 같다는 알림이 왔어. 로그인해서 수집기를 실제 화면에 맞게 고쳐줘.

Claude는 `python -m dentmoa probe moreden` 같은 명령으로 실제 화면을 저장합니다. 그 화면을 보고 수집기를 고친 뒤 테스트를 추가합니다.

## 다 끝난 뒤

수집기 마무리가 끝나면 네트워크 접근을 원래대로 줄여도 됩니다. 환경 변수의 비밀번호도 지워도 됩니다.
(2026-10-09 세션에서 모어덴·덴트포토 마무리가 끝났으니 지금 지워도 됩니다. 다음에 고칠 일이 생기면 다시 넣으면 됩니다.)
