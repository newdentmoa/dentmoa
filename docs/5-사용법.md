# 5. 사용법

설치와 알림 설정이 끝났다면, 이제 **받고 싶은 공고 조건**을 정하고 대시보드를 쓰는 방법을 알아봅니다.

---

## 대시보드 화면 구성

대시보드 위쪽에 메뉴가 4개 있습니다.

| 메뉴 | 하는 일 |
|---|---|
| **공고** | 모아 둔 공고 보기. **내 조건에 맞는 공고 / 전체 공고 / 관심(★)** 탭, 검색·필터 |
| **알림 조건** | 받을 공고 조건, 알림 시각, 마감 임박 알림, 확인할 사이트 |
| **계정·연결** | 모어덴·덴트포토 계정, 텔레그램, 메일 설정과 테스트 버튼 |
| **상태** | 다음 실행 시각, 사이트별 마지막 수집 결과, 실행 기록, **지금 수집·알림 실행**, **알림 미리보기**, 대시보드 비밀번호 바꾸기 |

## 알림은 언제, 어떻게 오나요?

- 하루 3번 — 기본 **08:10 · 12:40 · 18:20 무렵** (사이트에 매번 같은 시각에 접속하지 않도록 몇 분씩 무작위로 늦춥니다)
- 그 사이에 새로 올라온 공고 중 **알림 조건에 맞는 공고만** 모아서 한 번에 보냅니다.
- 한 번 알린 공고는 다시 알리지 않습니다. 여러 사이트에 똑같이 올라온 공고도 한 번만 알립니다.
- 공고마다 이런 내용이 붙습니다: 제목, 기관 종류·직위·분과·근무 형태, 지역, 기관 이름, 마감일(D-day), **본문 3줄 요약**, 원문 링크
- 맞는 새 공고가 없으면 알림을 보내지 않습니다. ('새 공고 없음' 알림도 받고 싶다면 **알림 조건** → **알림**에서 켤 수 있습니다.)
- 로그인 실패처럼 확인이 필요한 일이 생기면 **⚠️ 확인이 필요해요** 라는 안내가 함께 옵니다. → [6. 문제 해결](6-문제해결.md)

**알림 시각 바꾸기:** **알림 조건** → **알림** → **알림 시각** 칸 (1~4개). 사이트를 조용히 읽도록 하루 2~3번을 권합니다.

## 알림 조건 정하기 — 예시

**알림 조건** 화면에서 체크박스를 고르고 맨 아래 **저장**을 누릅니다.
저장하면 위쪽에 "현재 조건으로 최근 30일 공고 중 **N건**이 해당돼요" 가 나와서, 조건이 너무 좁거나 넓은지 바로 알 수 있습니다.

아래는 **소아치과 전문의가 대학병원·치과대학병원·종합병원·공공기관·장애인치과의 교수직이나 전임의 자리**를 찾는 경우의 예시입니다.

### 받을 글 종류

- ✅ 구인
- ⬜ 구직, ⬜ 기타 (양도·공지·결과발표 등)
- ✅ 치과의사 공고만 받기 (위생사·간호사 등 다른 직종 공고는 빼기)

### 기관 종류

| 고르기 | 항목 |
|---|---|
| ✅ | 치과대학병원·치과대학 |
| ✅ | 대학병원 치과 |
| ✅ | 종합병원·병원 치과 |
| ✅ | 공공병원·보건소 |
| ✅ | 장애인치과병원·구강진료센터 |
| ⬜ | 치과병원 (네트워크 포함) |
| ⬜ | 치과의원 (로컬) |
| ✅ (권장) | 기타 기관 — 글에서 기관 종류를 알아내지 못한 공고입니다. 주로 병원 게시판·공공기관 사이트에서 나와서, 켜 두면 놓치는 공고가 줄어듭니다. |

### 직위

| 고르기 | 항목 | 설명 |
|---|---|---|
| ✅ | 전임교원 (조교수 이상) | 교수 채용 |
| ✅ | 임상교수·진료교수 (비전임) | |
| ✅ | 전임의·임상강사 (펠로우) | |
| ✅ | 촉탁의·계약직·임기제 | 공공병원·보건소 공고는 직위가 따로 없으면 이것으로 분류됩니다. 꼭 켜 두세요. |
| ✅ | 봉직의 (페이닥터) | "소아치과 전문의 채용", "치과의사 채용"처럼 **직위 이름이 따로 없는** 대학병원·치과대학병원·종합병원·장애인치과 공고는 이것으로 분류됩니다. **꼭 켜 두세요.** 기관 종류에서 치과의원·치과병원을 껐으므로, 켜 두어도 동네 치과의 페이닥터 공고는 오지 않습니다. |
| ⬜ | 전공의·인턴 (수련) | |
| ⬜ | 기타 (동업·외래교수 등) | |

### 분과

- ✅ **소아치과** — 소아치과 전문의를 찾는 공고
- ✅ **일반의 혹은 분과무관** — 전문 분과를 따로 정하지 않은 공고. 장애인치과·보건소·공공병원 공고는 대부분 여기에 들어갑니다.
- 나머지 분과(교정과, 구강악안면외과 등)는 ⬜
- ✅ **'교정 가능자 우대'처럼 참고 분야만 맞아도 받기** — 켜면 "소아치과 전공자 우대"처럼 소아치과가 **우대 조건**으로만 적힌 공고도 받습니다.

> **이렇게 고르면:** "구강외과 전임의 모집"처럼 **다른 분과만** 찾는 공고는 빠지고, 소아치과 공고와 분과를 따지지 않는 공고는 들어옵니다.

### 근무 형태

- ✅ 풀타임
- ✅ 파트타임 (원하지 않으면 끄기)
- ⬜ 대진

근무 형태가 적혀 있지 않은 공고는 **풀타임**으로 봅니다.

### 지역

- ✅ **전국 (모든 지역)**

### 키워드

- **무조건 포함 키워드**
  ```
  임상교수
  진료교수
  ```
- **제외 키워드**
  ```
  치과위생사
  대진
  ```

설명은 아래 [지역 고르기](#지역-고르기)와 [키워드](#키워드-무조건-포함과-제외)를 보세요.

## 지역 고르기

**알림 조건** → **지역**에서 여러 곳을 함께 고를 수 있습니다.

| 고르는 방법 | 뜻 |
|---|---|
| **전국 (모든 지역)** | 지역을 따지지 않습니다. 이것을 고르면 다른 지역 선택은 무시됩니다. |
| **서울 전체** | 서울의 모든 구가 포함됩니다. |
| **구·시·군 고르기** → 예: 경기 **성남시**, **용인시** | 고른 곳만 포함됩니다. |

예: "서울 전체 + 경기 성남시 + 경기 용인시" 처럼 섞어서 고를 수 있습니다.

**지역이 애매한 공고는요?**

- 공고에 지역이 아예 없거나, '경기'처럼 **시·도만** 적혀 있어서 고른 구·시·군과 맞는지 알 수 없을 때가 있습니다.
- **지역이 불분명한 공고도 받기**를 켜 두면(기본) 이런 공고도 받고, **지역 확인 필요** 꼬리표가 붙습니다. 놓치는 공고가 없도록 켜 두는 것을 권합니다.
- '서울 전체'처럼 시·도 전체를 골랐다면, '서울'이라고만 적힌 공고도 바로 맞는 것으로 봅니다.
- 인천은 2026년 7월 행정구역 개편(제물포구·영종구·검단구)이 반영되어 있습니다.

## 키워드 (무조건 포함과 제외)

키워드는 **제목·기관 이름·본문** 어디에 있어도 찾습니다. 쉼표(,)나 줄바꿈으로 여러 개를 적습니다. 영어 대소문자는 구분하지 않습니다.

덴트모아는 이 순서로 판단합니다.

1. **글 종류** (구인/구직/기타) — 여기서 안 맞으면 끝
2. **무조건 포함 키워드**가 하나라도 있으면 → 나머지 조건과 상관없이 **받습니다**
3. **제외 키워드**가 하나라도 있으면 → **받지 않습니다**
4. 기관 종류·직위·분과·근무 형태·지역 조건을 모두 확인합니다

**예시 설명**

- **무조건 포함: `임상교수`, `진료교수`** — 이 말이 들어간 공고는 기관 종류·분과·지역이 조건 밖이어도 받습니다. 혹시 분류가 틀려도 놓치지 않게 해 주는 안전장치입니다.
  - 무조건 포함은 **치과의사 공고만 받기**까지 건너뜁니다. 그래서 대학 전체 교원 채용 게시판에 올라온 "의과대학 임상교수" 같은 의사 공고가 가끔 섞일 수 있습니다. 그런 공고는 **숨기기**를 누르면 됩니다.
- **제외: `치과위생사`, `대진`** — 이 말이 들어간 공고는 받지 않습니다.
- 포함 키워드와 제외 키워드가 **둘 다** 있는 공고는 **받습니다** (포함이 먼저).

**주의할 점**

- 띄어쓰기까지 똑같아야 찾습니다. `임상교수` 와 `임상 교수` 는 다른 말로 봅니다. 둘 다 쓰일 수 있다면 두 가지를 모두 적으세요.
- 제외 키워드는 **본문 전체**에서 찾습니다. 예를 들어 `치과위생사`를 넣으면, 본문에 "치과위생사 3명 근무 중"이라고 적힌 **치과의사 공고**까지 빠질 수 있습니다.
  위생사 공고는 이미 **치과의사 공고만 받기**가 걸러 주므로, 제외 키워드는 꼭 필요할 때만, 되도록 구체적인 말로 넣으세요.
- 특정 병원 공고는 무조건 받고 싶다면 병원 이름을 무조건 포함에 넣으세요. 예: `서울대학교치과병원`, `보라매병원`

## 공고 화면 쓰기

**공고** 메뉴에서 모아 둔 공고를 봅니다.

- **탭**: 내 조건에 맞는 공고 / 전체 공고 / 관심(★)
- **검색·필터**: 검색어, 기관 종류, 직위, 분과, 근무 형태, 시·도, 출처, 기간(최근 7일~1년)
  - **숨긴 글 보기**: 숨긴 공고도 보기
  - **구직·기타 글 포함**: 구직 글, 양도·공지 글, 치과의사가 아닌 직종 공고도 보기
- **공고 카드**
  - 꼬리표: 기관 종류, 직위, 분과, 근무 형태 (예: `대학병원 · 전임의 · 소아 · 풀타임`)
  - 마감 배지: `D-5` 처럼 남은 날짜. 3일 이내는 눈에 띄는 색으로 표시됩니다. `채용시 마감`, `마감됨` 도 있습니다.
  - **다른 출처에도 있음**: 같은 공고가 다른 사이트에도 올라와 있다는 뜻
  - 버튼: **☆ 관심**, **숨기기**, **원문 보기**
- 제목을 누르면 **상세 화면**: 3줄 요약, 본문, 분류 근거, 알림 조건과 비교, 같은 공고 목록

## ★ 관심 표시와 마감 알림

- 마음에 드는 공고는 **☆ 관심**을 누르면 **★ 관심**으로 바뀌고, **관심(★)** 탭에 모입니다.
- 관심 공고는 알림에서도 ⭐ 로 표시됩니다.
- 보기 싫은 공고는 **숨기기**를 누르면 목록과 알림에서 빠집니다. (**숨긴 글 보기**로 다시 찾을 수 있습니다.)

**마감 임박 알림** (**알림 조건** → **알림** → **마감 임박 알림**)

- **마감이 다가오면 한 번 더 알려 주기**를 켜면, 마감 **N일 전부터**(기본 3일) 공고마다 **한 번** 더 알려 줍니다.
- 대상: 알림으로 받았던 공고(지금도 알림 조건에 맞는 것)와 관심(★) 공고
- **관심(★) 공고만**을 켜면 관심 표시한 공고만 마감 알림을 보냅니다. 알림이 너무 많다면 켜 보세요.
- 글에 마감일이 없는 공고(예: "채용시 마감")는 마감 알림이 가지 않습니다. 원문을 꼭 확인하세요.

## 분류가 틀릴 수 있어요 — "왜 이렇게 분류됐나요?"

덴트모아는 AI가 아니라 **정해진 규칙**으로 분류합니다. 글에 쓰인 말(예: "전임의", "소아치과", "보건소")을 보고 판단하기 때문에, 글이 특이하게 쓰여 있으면 틀릴 수 있습니다.

**왜 그렇게 분류됐는지 확인하는 방법**

1. 공고 제목을 눌러 상세 화면으로 갑니다.
2. **왜 이렇게 분류됐나요?** 표를 봅니다.

   | 항목 | 분류 | 근거 (글에서 찾은 말) |
   |---|---|---|
   | 기관 종류 | 대학병원 치과 | "○○대학교병원" |
   | 직위 | 전임의·임상강사 (펠로우) | "전임의" |
   | 분과 | 소아치과 | "소아치과" |
   | 근무 형태 | 풀타임 `추정` | — |

   - **추정** 꼬리표는 글에서 단서를 찾지 못해 **기본값**으로 정했다는 뜻입니다.
     (직위가 없으면 '봉직의', 공공병원·보건소는 '촉탁의·계약직' / 근무 형태가 없으면 '풀타임')
3. 그 아래 **알림 조건과 비교**에서, 알림 조건에 맞는지와 **맞지 않는 항목**을 볼 수 있습니다. 예: "기관: 치과의원 (로컬)", "제외 키워드: 대진"

**분류가 틀렸을 때**

- 꼭 받아야 할 공고가 빠졌다면 → 그 공고에만 있는 말(병원 이름, "임상교수" 등)을 **무조건 포함 키워드**에 넣습니다.
- 필요 없는 공고가 자꾸 온다면 → **제외 키워드**를 넣거나, 그 공고를 **숨기기** 합니다.
- 같은 종류의 실수가 반복된다면 → Claude Code 세션에서 공고 원문 주소와 함께 "이 공고가 ○○로 분류돼야 하는데 △△로 분류됐어. 규칙을 고쳐줘" 라고 요청하면 됩니다. 규칙이 바뀌면 이미 모아 둔 공고도 자동으로 다시 분류됩니다.

## 지금 바로 확인해 보기

- **상태** → **지금 수집·알림 실행**: 예약 시각을 기다리지 않고 바로 수집하고, 맞는 새 공고가 있으면 알림을 보냅니다. 사이트를 천천히 읽기 때문에 몇 분 걸립니다. 잠시 뒤 새로고침하세요.
- **상태** → **알림 미리보기**: 다음 알림에 어떤 공고가 들어갈지 보내지 않고 미리 봅니다.
- **상태** → **출처별 마지막 수집**: 사이트마다 마지막으로 언제, 몇 건을 가져왔는지, 실패했다면 왜 실패했는지 보여 줍니다.

## 수집 설정 (보통은 그대로 두세요)

**알림 조건** → **수집**

- **확인할 사이트**: 쓰지 않는 사이트는 끌 수 있습니다. (예: 덴트포토 계정이 없다면 덴트포토 끄기)
- **처음 수집할 때 가져올 기간**: 처음 실행할 때 며칠 전 공고까지 가져올지 (기본 30일)
- **글을 열 때마다 쉬는 시간**: 사이트에 부담을 주지 않도록 글 하나를 열 때마다 쉬는 시간 (기본 3~8초). 줄이지 않는 것을 권합니다.
