# 2. 설치하기

[1. 서버 만들기](1-서버-만들기.md)를 끝낸 뒤에 합니다. 서버에 덴트모아를 설치하고, 대시보드 비밀번호를 정합니다.

**걸리는 시간:** 30분쯤 (대부분은 설치가 끝나기를 기다리는 시간)
**준비물:** 컴퓨터, GitHub 계정(`newdentmoa`), Lightsail의 SSH 창

---

## 1단계. GitHub 읽기 전용 토큰 만들기

덴트모아 코드가 있는 GitHub 저장소(`newdentmoa/dentmoa`)는 **비공개**입니다.
서버가 코드를 받으려면 **토큰**이라는 열쇠가 필요합니다. **이 저장소 하나만, 읽기만** 할 수 있는 토큰을 만듭니다.

1. 컴퓨터 브라우저에서 <https://github.com> 에 `newdentmoa` 계정으로 로그인합니다.
2. 오른쪽 위 **프로필 사진** → **Settings** 를 누릅니다.
3. 왼쪽 메뉴 맨 아래의 **Developer settings** 를 누릅니다.
4. **Personal access tokens** → **Fine-grained tokens** → **Generate new token** 을 누릅니다.
   (바로 가기: <https://github.com/settings/personal-access-tokens/new>)
5. 다음처럼 채웁니다.

   | 항목 | 넣을 값 |
   |---|---|
   | **Token name** | `dentmoa-server` |
   | **Expiration** (만료) | 고를 수 있는 가장 긴 기간 (예: **Custom** 으로 1년 뒤 날짜). 만료되면 업데이트할 때 새 토큰이 필요합니다. |
   | **Resource owner** | `newdentmoa` |
   | **Repository access** | **Only select repositories** → `newdentmoa/dentmoa` 선택 |
   | **Permissions** | **Repository permissions** 의 **Contents** → **Read-only** |

   - 화면에 **Add permissions** 버튼이 있으면, 눌러서 **Contents** 를 고른 뒤 Access를 **Read-only** 로 둡니다.
   - **Metadata: Read-only** 가 저절로 함께 들어가는 것은 정상입니다.
   - 다른 권한은 건드리지 않습니다.
6. 맨 아래 **Generate token** 을 누릅니다.
7. `github_pat_` 로 시작하는 긴 글자가 나옵니다. 옆의 복사 버튼을 눌러 복사하고, **메모장**에 잠시 붙여 둡니다.
   **이 화면을 벗어나면 토큰을 다시 볼 수 없습니다.** (잃어버리면 새로 만들면 됩니다.)

> 토큰은 서버의 코드 폴더 설정(`~/dentmoa/.git/config`)에 저장되어 업데이트할 때 쓰입니다.
> 읽기만 가능하고 이 저장소만 볼 수 있지만, 그래도 다른 사람에게 보여주지 마세요.

## 2단계. 설치 명령 만들기 (메모장에서)

윈도우 **메모장**을 열고 아래 한 줄을 붙여넣습니다.

```
cd ~ && git clone https://<토큰>@github.com/newdentmoa/dentmoa.git && cd dentmoa && sudo bash deploy/install.sh
```

`<토큰>` 부분을 1단계에서 복사한 토큰으로 바꿉니다. **꺾쇠 `<` `>` 도 지웁니다.** 바꾸고 나면 이런 모양입니다.

```
cd ~ && git clone https://github_pat_11ABCDEFG0123456789_abcdefghijklmnop@github.com/newdentmoa/dentmoa.git && cd dentmoa && sudo bash deploy/install.sh
```

> **브랜치 확인:** GitHub의 `newdentmoa/dentmoa` 저장소 첫 화면(main 브랜치)에 `deploy` 폴더가 **보이지 않는다면**,
> 프로그램이 아직 main 에 합쳐지지 않은 것입니다. 이때는 `git clone` 바로 뒤에 `-b claude/dentist-job-alert-app-xmcl6s` 를 넣은 아래 명령을 씁니다.
>
> ```
> cd ~ && git clone -b claude/dentist-job-alert-app-xmcl6s https://<토큰>@github.com/newdentmoa/dentmoa.git && cd dentmoa && sudo bash deploy/install.sh
> ```

## 3단계. 서버에서 설치 실행

1. Lightsail의 SSH 창을 엽니다. ([1장 5단계](1-서버-만들기.md#5단계-서버에-접속하기-브라우저-ssh))
2. 메모장에서 만든 한 줄을 복사해 SSH 창에 붙여넣고 **Enter** 를 누릅니다.
3. 설치가 단계별로 진행됩니다. `[1/8]` 부터 `[8/8]` 까지 차례로 나옵니다.

   | 단계 | 하는 일 |
   |---|---|
   | 1 | 도커(프로그램 상자) 설치 |
   | 2 | 메모리가 적으면 보충 메모리(스왑) 2GB 만들기 |
   | 3 | 서버 IP로 대시보드 주소 만들기 |
   | 4 | 설정 파일(`deploy/.env`) 만들기 |
   | 5 | 데이터 폴더 만들기 |
   | 6 | 프로그램 만들고 시작하기 — **처음에는 10~20분** 걸립니다 |
   | 7 | 매일 새벽 자동 백업 등록 |
   | 8 | 잘 켜졌는지 확인 |

4. 6단계에서 글자가 한참 올라갑니다. 정상이니 **창을 닫지 말고 기다립니다.**
5. 마지막에 이런 화면이 나오면 성공입니다.

   ```
   ══════════════════════════════════════════════════════════════
    덴트모아 설치가 끝났습니다!
   ══════════════════════════════════════════════════════════════

    휴대폰이나 컴퓨터 브라우저에서 아래 주소를 여세요:

        https://3-35-123-45.sslip.io
   ```

   이 주소를 메모해 둡니다. (숫자는 서버마다 다릅니다.)

**중간에 문제가 생기면**

- **SSH 창이 끊겼어요** → 다시 접속해서 아래 명령을 입력합니다. 이미 끝난 단계는 건너뛰고 이어서 진행합니다.
  ```
  cd ~/dentmoa && sudo bash deploy/install.sh
  ```
- **`destination path 'dentmoa' already exists`** → 코드는 이미 받았다는 뜻입니다. 바로 위 명령으로 설치만 다시 실행합니다.
- **`Authentication failed` / `Repository not found`** → 토큰이 잘못 들어갔습니다. 토큰을 다시 복사해서 명령을 고쳐 보세요. (꺾쇠 `<` `>` 를 지웠는지, 1단계에서 저장소를 골랐는지 확인)

## 4단계. 대시보드 열고 비밀번호 정하기

> **설치가 끝나면 바로 하세요.** 처음 비밀번호를 정할 때는 설치 화면 마지막에 나온 **6자리 설치 코드**가 필요합니다.
> (코드가 있어야 하므로 주소를 알아낸 다른 사람이 먼저 비밀번호를 정할 수는 없습니다.)
> 코드를 잊었다면 SSH 창에서 `cd ~/dentmoa && sudo grep SETUP_CODE deploy/.env` 로 다시 볼 수 있습니다.

1. 휴대폰 브라우저(크롬, 삼성 인터넷 등)에서 설치 화면에 나온 주소(`https://…sslip.io`)를 엽니다.
2. **덴트모아에 오신 것을 환영해요** 화면이 나옵니다.
3. **설치 코드**(6자리 숫자)를 넣고, 대시보드 비밀번호(8자 이상)를 두 번 넣은 뒤 **비밀번호 정하기**를 누릅니다.
   - 사이트 비밀번호와 다른, 덴트모아 전용 비밀번호로 정하는 것이 좋습니다.
   - 한 번 로그인하면 그 기기에서는 30일 동안 로그인이 유지됩니다.
4. 저절로 **계정·연결** 화면으로 넘어갑니다.
5. **모어덴**, **덴트포토** 칸에 아이디·비밀번호를 넣고 각각 **저장**을 누릅니다.
   - 모어덴은 **카카오 로그인이 아닌 아이디·비밀번호 로그인** 정보가 필요합니다. 카카오로만 가입했다면 모어덴에서 아이디·비밀번호 로그인을 먼저 만들어 주세요.
   - 저장한 비밀번호는 보안을 위해 화면에 다시 보이지 않고 **저장됨 ✓** 으로만 표시됩니다.
6. 화면 아래 **출처별 연결 테스트**에서 **모어덴**, **덴트포토** 버튼을 눌러 로그인이 되는지 확인합니다. (수십 초 걸릴 수 있습니다.)

**휴대폰 홈 화면에 추가하기 (앱처럼 쓰기)**
크롬: 오른쪽 위 **⋮** → **홈 화면에 추가** / 삼성 인터넷: 아래 **≡** → **현재 페이지 추가** → **홈 화면**

## sslip.io 주소란?

- `3-35-123-45.sslip.io` 는 도메인을 사지 않아도 IP 주소만으로 쓸 수 있는 **무료 주소**입니다. 이 주소는 IP `3.35.123.45` 로 연결됩니다.
- 보안 인증서(https 자물쇠)는 덴트모아에 들어 있는 웹 서버(Caddy)가 **자동으로 받고 자동으로 갱신**합니다. 따로 할 일이 없습니다.
- **내 도메인을 쓰고 싶다면:** 도메인 관리 화면에서 A 레코드를 서버의 고정 IP로 지정한 뒤, 서버에서 아래 명령을 실행합니다.
  ```
  cd ~/dentmoa && sudo bash deploy/install.sh 내도메인.com
  ```

## https 주소가 열리지 않거나 인증서 오류가 나요

"연결이 비공개로 설정되어 있지 않습니다", "사이트에 연결할 수 없음" 같은 화면이 나올 때입니다.

1. **몇 분 기다렸다가 새로고침합니다.** 처음 인증서를 받는 데 1~5분 걸릴 수 있습니다.
   sslip.io 는 많은 사람이 함께 쓰는 무료 주소라서, 드물게 인증서 발급이 잠시 막힐 때가 있습니다(발급 횟수 제한). 웹 서버가 저절로 다시 시도하므로 몇 시간 뒤 해결되는 경우가 많고, 급하다면 내 도메인을 쓰는 방법도 있습니다.
2. **방화벽을 확인합니다.** Lightsail 인스턴스 → **네트워킹** 탭 → **IPv4 방화벽**에 **HTTP (80)** 과 **HTTPS (443)** 가 모두 있어야 합니다. ([1장 4단계](1-서버-만들기.md#4단계-방화벽-열기-http-80-https-443))
   규칙을 지금 추가했다면, 웹 서버가 인증서를 바로 다시 받도록 아래 명령으로 다시 시작하고 2~3분 뒤 열어 봅니다. (실패가 쌓이면 웹 서버가 다시 시도하는 간격이 길어지기 때문입니다.)
   ```
   cd ~/dentmoa/deploy && sudo docker compose restart caddy
   ```
3. **고정 IP를 확인합니다.** 주소의 숫자가 Lightsail의 고정 IP와 같은지 봅니다. 고정 IP를 설치 **뒤에** 붙였다면 주소가 달라졌을 수 있습니다. 이때는 서버에서 아래 명령으로 주소를 다시 만듭니다.
   ```
   cd ~/dentmoa && sudo bash deploy/install.sh auto
   ```
4. 그래도 안 되면 웹 서버 기록을 봅니다.
   ```
   cd ~/dentmoa/deploy && sudo docker compose logs --tail 50 caddy
   ```
   이 내용을 복사해 Claude에게 보여 주면 원인을 찾는 데 도움이 됩니다. (비밀번호 같은 것은 들어 있지 않습니다.)

더 많은 문제 해결 방법은 [6. 문제 해결](6-문제해결.md)에 있습니다.
