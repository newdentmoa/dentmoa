# 3. 텔레그램 설정

새 공고 알림을 휴대폰 **텔레그램**으로 받도록 설정합니다.
텔레그램에서 나만 쓰는 알림용 **봇**(자동 메시지 계정)을 하나 만들고, 그 봇의 열쇠(**토큰**)를 대시보드에 넣는 방식입니다.

**걸리는 시간:** 10분
**준비물:** 안드로이드 휴대폰, 덴트모아 대시보드(휴대폰 브라우저에서 열어 두면 편합니다)

> 휴대폰 한 대로 텔레그램과 대시보드를 오가며 하면 됩니다. 복사·붙여넣기만 할 줄 알면 충분합니다.

---

## 1단계. 텔레그램 설치하고 가입하기

1. **Play 스토어**에서 `텔레그램` 을 검색해 **Telegram** 앱을 설치합니다. (이미 쓰고 있다면 3단계로)
2. 앱을 열고 **메시지 보내기 시작**(Start Messaging)을 누릅니다.
3. 휴대폰 번호를 넣고, 문자나 전화로 온 인증 번호를 입력합니다.
4. 이름을 적으면 가입이 끝납니다.

## 2단계. BotFather 에게 봇 만들어 달라고 하기

**BotFather** 는 텔레그램이 공식으로 운영하는, 봇을 만들어 주는 계정입니다.

1. 텔레그램 첫 화면 오른쪽 위의 **돋보기(검색)** 를 누르고 `BotFather` 를 검색합니다.
2. 이름 옆에 **파란 체크 표시**가 있는 **BotFather** (`@BotFather`) 를 누릅니다.
   - 비슷한 이름의 가짜 계정이 있으니 **파란 체크 표시**를 꼭 확인하세요.
3. 아래쪽의 **시작**(START) 버튼을 누릅니다.
4. 메시지 입력 칸에 아래 글자를 그대로 적어 보냅니다.
   ```
   /newbot
   ```
5. **봇 이름**을 물어봅니다 ("Alright, a new bot. How are we going to call it?").
   아무 이름이나 보냅니다. 예: `덴트모아 알림`
6. **봇 아이디(username)** 를 물어봅니다 ("Now let's choose a username for your bot.").
   - 영어·숫자·밑줄(_)만 쓸 수 있고, **반드시 `bot` 으로 끝나야** 합니다.
   - 예: `dentmoa_kim_bot`, `dentmoa2026_bot`
   - "Sorry, this username is already taken" 이 나오면 이미 있는 이름입니다. 다른 이름을 보내세요.
7. 성공하면 "Done! Congratulations on your new bot." 으로 시작하는 메시지가 옵니다. 이 메시지 안에 두 가지가 있습니다.
   - `t.me/dentmoa_kim_bot` 같은 **내 봇 링크**
   - "Use this token to access the HTTP API:" 아래의 **토큰** — `123456789:AAH...` 처럼 숫자, 쌍점(:), 긴 영문이 이어진 글자

> **토큰은 내 봇을 조종하는 열쇠입니다.** 다른 사람에게 보여주거나 채팅방에 올리지 마세요.

## 3단계. 토큰을 대시보드에 넣기

1. BotFather 메시지의 **토큰 부분을 길게 눌러** 복사합니다. (토큰을 한 번 누르면 바로 복사되기도 합니다.)
   - 토큰 앞뒤의 다른 글자가 같이 복사되지 않게 주의합니다.
2. 휴대폰 브라우저에서 덴트모아 대시보드를 열고 위쪽 메뉴의 **계정·연결**을 누릅니다.
3. **텔레그램** 칸의 **봇 토큰**에 붙여넣습니다.
4. **채팅 ID** 칸은 비워 둡니다. (다음 단계에서 자동으로 찾습니다.)
5. **텔레그램 저장** 버튼을 누릅니다. 위쪽에 "텔레그램 정보를 저장했습니다." 가 나오면 됩니다.

## 4단계. 내 봇에게 '시작' 누르기

봇은 내가 먼저 말을 걸어야 나에게 메시지를 보낼 수 있습니다.

1. 텔레그램으로 돌아가 BotFather 메시지의 `t.me/…bot` **링크를 누릅니다.**
   (또는 검색창에 내 봇 아이디를 검색합니다.)
2. 내 봇 대화창이 열리면 아래쪽의 **시작**(START) 버튼을 누릅니다.
   - 봇이 아무 대답을 하지 않아도 정상입니다.

## 5단계. 채팅 ID 찾고 테스트하기

1. 대시보드의 **계정·연결** → **텔레그램** 칸 아래의 **채팅 ID 자동 찾기** 버튼을 누릅니다.
2. "채팅 ID를 찾아서 저장했어요." 가 나오면 성공입니다.
   - "채팅 ID를 찾지 못했어요" 가 나오면: 텔레그램에서 내 봇에게 `안녕` 처럼 아무 메시지나 하나 보낸 뒤 다시 누릅니다.
3. **테스트 메시지 보내기** 버튼을 누릅니다.
4. 텔레그램의 내 봇 대화창에 덴트모아 테스트 메시지가 오면 **설정 끝**입니다. 🎉

## 6단계. 알림 켜져 있는지 확인

대시보드 **알림 조건** → **알림** 칸에서 **텔레그램으로 받기**가 체크되어 있는지 확인합니다. (처음에는 켜져 있습니다.)

**알림 소리:** 텔레그램에서 내 봇 대화창 → 위쪽 봇 이름 → **알림**(종 모양)에서 소리나 진동을 바꿀 수 있습니다. 대화창을 **고정**해 두면 찾기 쉽습니다.

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 테스트 메시지가 안 와요 | 내 봇 대화창에서 **시작**을 눌렀는지 확인 → **채팅 ID 자동 찾기**를 다시 누르고 → **테스트 메시지 보내기** |
| "토큰이 올바르지 않다"는 오류 | 토큰을 다시 복사해서 **봇 토큰** 칸에 새로 붙여넣고 저장. 앞뒤에 다른 글자가 섞이지 않았는지 확인 |
| 토큰을 잃어버렸어요 | BotFather 에게 `/mybots` → 내 봇 → **API Token** 을 누르면 다시 볼 수 있습니다 |
| 토큰이 남에게 보였어요 | BotFather 에게 `/mybots` → 내 봇 → **API Token** → **Revoke current token** 으로 새 토큰을 받고, 대시보드에 새로 넣습니다 |
| 봇을 차단했거나 대화를 지웠어요 | 내 봇을 다시 찾아 **시작** → **채팅 ID 자동 찾기** |
