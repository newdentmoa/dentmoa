# 4. 메일 설정

새 공고 알림을 **메일**로도 받도록 설정합니다. 텔레그램만 쓸 거라면 이 단계는 건너뛰어도 됩니다.

덴트모아는 **Gmail 계정 하나를 빌려서** 메일을 보냅니다. 이때 Gmail 로그인 비밀번호가 아니라,
프로그램 전용으로 만드는 16자리 **앱 비밀번호**를 씁니다. 앱 비밀번호는 언제든 지울 수 있어서 안전합니다.

**걸리는 시간:** 10분
**준비물:** Gmail 계정 (알림을 보낼 계정), 덴트모아 대시보드

> **보내는 계정**과 **받는 주소**는 같아도 됩니다. 내 Gmail에서 내 Gmail로 보내는 식입니다.
> 개인 메일 계정에 앱 비밀번호를 만드는 것이 꺼려지면, 알림 전용 Gmail 계정을 새로 하나 만들어 써도 됩니다.

---

## 1단계. 2단계 인증 켜기

앱 비밀번호는 **2단계 인증이 켜진 계정**에서만 만들 수 있습니다. 이미 켜져 있다면 2단계로 넘어갑니다.

1. 컴퓨터나 휴대폰 브라우저에서 <https://myaccount.google.com> 에 들어갑니다. (알림을 **보낼** Gmail 계정으로 로그인)
   - 휴대폰 Gmail 앱에서는: 오른쪽 위 프로필 사진 → **Google 계정 관리**
2. **보안**(또는 **보안 및 로그인**) 메뉴를 누릅니다. 휴대폰에서는 위쪽 탭에 있습니다.
3. **Google에 로그인하는 방법** 부분의 **2단계 인증**을 누릅니다.
4. **2단계 인증 사용 설정**을 누르고 화면 안내대로 휴대폰 번호를 확인합니다.
5. "2단계 인증 사용 중" 이 보이면 됩니다.

## 2단계. 앱 비밀번호 만들기

1. <https://myaccount.google.com/apppasswords> 에 들어갑니다.
   (또는 Google 계정 화면 맨 위 검색창에 `앱 비밀번호` 를 검색합니다.)
2. 비밀번호를 한 번 더 물어보면 Gmail 비밀번호를 넣습니다.
3. **앱 이름**에 `덴트모아` 라고 적고 **만들기**를 누릅니다.
4. 노란 상자 안에 **16자리 영문** 비밀번호가 나옵니다. 예: `abcd efgh ijkl mnop`
   - 이 창을 닫으면 다시 볼 수 없습니다. **바로 복사**해서 다음 단계에 씁니다. (잃어버리면 지우고 새로 만들면 됩니다.)
5. **완료**를 누릅니다.

**"앱 비밀번호" 메뉴가 안 보여요**

- 2단계 인증이 꺼져 있으면 보이지 않습니다. 1단계를 먼저 하세요.
- 회사·학교에서 받은 계정(Google Workspace)은 관리자가 막아 두었을 수 있습니다. 개인 Gmail 계정을 쓰세요.
- **고급 보호 프로그램**에 가입한 계정은 앱 비밀번호를 쓸 수 없습니다.

## 3단계. 대시보드에 넣기

1. 덴트모아 대시보드 → 위쪽 메뉴 **계정·연결** → **메일** 칸으로 갑니다.
2. 다음처럼 넣습니다.

   | 칸 | 넣을 값 |
   |---|---|
   | **SMTP 서버** | 비워 둡니다 (기본값 `smtp.gmail.com` 사용) |
   | **포트** | 비워 둡니다 (기본값 `587` 사용) |
   | **보내는 Gmail 주소** | 앱 비밀번호를 만든 Gmail 주소 (예: `myname@gmail.com`) |
   | **앱 비밀번호** | 2단계에서 복사한 16자리 (띄어쓰기는 있어도 괜찮습니다) |
   | **받는 주소** | 알림을 받을 메일 주소. 여러 곳이면 쉼표(,)로 구분 |

   - SMTP 서버와 포트 옆에 **기본값 사용 (smtp.gmail.com)**, **기본값 사용 (587)** 이 보이면 그대로 두면 됩니다.
3. **메일 저장** 버튼을 누릅니다.
4. **메일 테스트** 버튼을 누릅니다.
5. 받는 주소의 메일함에 **덴트모아 테스트 메일**이 오면 설정 끝입니다. 🎉
   - 안 보이면 **스팸함**을 확인하세요. 스팸함에 있으면 메일을 열고 **스팸 아님**을 눌러 두면 다음부터 받은편지함으로 옵니다.

## 4단계. 알림 켜져 있는지 확인

대시보드 **알림 조건** → **알림** 칸에서 **메일로 받기**가 체크되어 있는지 확인합니다. (처음에는 켜져 있습니다.)

다음은 → **[5. 사용법](5-사용법.md)** 에서 받고 싶은 공고 조건을 정합니다.

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| "메일 로그인 실패: Gmail은 일반 비밀번호가 아니라 '앱 비밀번호' 16자리를…" | Gmail 로그인 비밀번호를 넣었거나 앱 비밀번호를 잘못 복사했습니다. 앱 비밀번호를 새로 만들어 다시 넣으세요. **보내는 Gmail 주소**가 앱 비밀번호를 만든 계정과 같은지도 확인하세요. |
| "받는 메일 주소가 올바르지 않습니다" | **받는 주소** 칸의 철자를 확인하세요. |
| 테스트는 성공했는데 메일이 안 보여요 | 스팸함, 프로모션·소셜 탭을 확인하세요. |
| Gmail 비밀번호를 바꿨더니 메일이 안 와요 | Google 계정 비밀번호를 바꾸면 앱 비밀번호가 지워질 수 있습니다. 앱 비밀번호를 새로 만들어 다시 넣으세요. |

## Gmail 말고 다른 메일로 보내고 싶다면 (선택)

**네이버 메일**로 보낼 수도 있습니다. 화면 이름은 바뀔 수 있으니 네이버 도움말도 함께 확인하세요.

1. 네이버 메일 → **환경설정** → **POP3/IMAP 설정**에서 **IMAP/SMTP 사용**을 **사용함**으로 바꾸고 저장합니다.
2. 네이버 2단계 인증을 쓰고 있다면, 네이버 **보안설정**에서 **애플리케이션 비밀번호**를 만들어 비밀번호 대신 씁니다.
3. 대시보드에 **SMTP 서버** `smtp.naver.com`, **포트** `587`, **보내는 주소** `아이디@naver.com`, 비밀번호 칸에 네이버 비밀번호(또는 애플리케이션 비밀번호)를 넣고 저장 → **메일 테스트**.
